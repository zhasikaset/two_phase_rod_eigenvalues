# Failure of Periodic Maximizers for Higher Eigenvalues of Two-Phase Rods

This repository contains the code used alongside our paper

**Zhassulan Asset and Durvudkhan Suragan,  
“Failure of Periodic Maximizers for Higher Eigenvalues of Two-Phase Rods.”**

The code is divided into three parts:

- rigorous interval-arithmetic verification;
- numerical experiments and reproduction of the values reported in the paper;
- generation of the figures.

## Repository structure

```text
certificate/
    certificate.py
    certificate_output.txt

numerical/
    fast.py
    reproduce.py
    reproduce_output.txt

figures/
    figures.py
    generated/
        fig_clamped_sublevel.pdf
        fig_densities.pdf
```

## Rigorous certificate

The file

```text
certificate/certificate.py
```

contains the rigorous computer-assisted verification used in the paper.

It uses exact rational arithmetic together with interval enclosures. In particular, it checks the sign conditions and root-exclusion estimates needed for the finite-contrast examples.

The certified comparisons include

$$
\lambda_2(\rho_{\mathrm{per},2})<22<23<\lambda_2(\rho_*)
$$

$$
\lambda_3(\rho_{\mathrm{per},3})<109<120<\lambda_3(\rho_{3,*})
$$

and

$$
\Lambda_2(\rho_{\mathrm{per},2})<53<66<\Lambda_2(\rho_{\sharp})
$$

The same script also verifies the interval estimates used in the clamped weak-contrast argument.

No external Python packages are needed to run the certificate.

To run it from the repository root:

```bash
python certificate/certificate.py
```

A successful run ends with

```text
ALL CERTIFICATES PASSED
```

The output from our run is included in

```text
certificate/certificate_output.txt
```

## Numerical computations

The `numerical` folder contains the floating-point computations used while exploring the problem and for reproducing the numerical values quoted in the paper.

`fast.py` contains the finite-element calculations, the rearrangement iteration, and the floating-point transfer-matrix solver.

`reproduce.py` reproduces the numerical eigenvalues and the auxiliary values reported in the manuscript.

To run it:

```bash
cd numerical
python reproduce.py
```

The corresponding output is included in

```text
reproduce_output.txt
```

These computations are numerical and are not used as the rigorous proof of the certified inequalities above.

## Figures

The figures used in the manuscript are generated by

```text
figures/figures.py
```

To generate them:

```bash
cd figures
python figures.py
```

The generated PDF files are also included in

```text
figures/generated/
```

## Requirements

The rigorous certificate uses only the Python standard library.

The numerical and figure scripts require

```text
numpy
scipy
matplotlib
mpmath
```

They can be installed with

```bash
pip install -r requirements.txt
```
